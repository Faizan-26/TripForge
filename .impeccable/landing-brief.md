# Landing page — Route Room

- **Scope and mode:** Persuade landing page in `frontend/app/page.tsx`. A traveler explores the offer and starts a trip request; the real chat workspace remains out of scope.
- **Action and auth:** The hero has one plain-language input. Submission preserves the request and reveals an email OTP handoff; direct Supabase authentication is intentionally pending project credentials and client setup.
- **Direction:** Light Route Room: warm map-paper ground, softly elevated ink-blue planning objects, citron departure signals, rounded edges, and route-line motion. The hero demonstrates a customer-facing journey taking shape, never internal agent stages. The approved composition is `.impeccable/mocks/landing-route-room-a.png`.
- **Proof and boundaries:** Synthetic agent workflow UI is explicitly illustrative. No customer claims, results, prices, booking, or functioning chat are implied.
- **Interaction:** Smooth anchors, scroll-triggered progressive reveals, and full reduced-motion fallback. Mobile compresses the route board into a readable single-column sequence.
